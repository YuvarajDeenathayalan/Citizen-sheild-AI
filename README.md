# CitizenShield AI

CitizenShield AI is an AI-powered civic safety and cyber awareness platform designed to help citizens identify scams, access legal guidance, report public issues, and receive real-time safety assistance through an intelligent digital dashboard.

The platform combines scam detection, legal assistance, emergency support, complaint management, and public safety analytics into a single modern web application. Users can analyze suspicious messages, detect phishing attempts, receive AI-generated risk assessments, and explore guidance for cybercrime and public safety concerns.

Built using HTML, CSS, JavaScript, Python FastAPI, and AI-driven logic, CitizenShield AI demonstrates full-stack development, API integration, cybersecurity awareness, and intelligent automation. The project aims to make digital safety tools more accessible, interactive, and user-friendly for everyday citizens.

Key Features:

* AI-powered scam message detection
* Legal assistance and cyber guidance
* Public complaint management system
* Safety alerts dashboard
* Real-time frontend-backend API integration
* Modern responsive UI with analytics dashboard

CitizenShield AI is designed as a scalable civic-tech platform suitable for hackathons, internships, portfolio showcases, and real-world public safety applications.
